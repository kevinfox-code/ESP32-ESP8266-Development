# ESP32 and ESP8266 Development

Small ESP32 and ESP8266 microcontroller projects, connectivity experiments,
and hardware references.

## Getting started

Use the project-specific instructions in each folder. Select the matching
board in the ESP-IDF or Arduino toolchain, confirm the serial port, and verify
the board’s 3.3 V power and pinout before flashing.

## Project areas

- Basic blink and GPIO experiments
- Bluetooth SPP
- ESP32-C6 display and REST experiments
- Board datasheets and pinout references
